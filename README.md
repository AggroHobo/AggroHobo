# Hi, I’m AggroHobo

Welcome! I’m an independent developer building local AI, creative tools, and desktop software.

My flagship project is **Seven / A-07**, an experimental local-first AI assistant. I’m working toward privacy-conscious personal assistance that combines natural conversation, memory, visual awareness, and user-authorized desktop interaction—running locally whenever practical.

## Seven / A-07

**Status: Active experimental prototype**

### Implemented or demonstrated

- **Local inference and text conversation:** LM Studio and Qwen-based models running on an NVIDIA RTX 3060 12GB, with conversations through local model interfaces and prototype launchers.
- **Prototype components:** Memory, knowledge retrieval, conversation history, and tool permissions, with automated tests.
- **Tool and speech experiments:** Successful individual tool calls in early tool/MCP integrations; speech-to-text and text-to-speech components tested separately.

These demonstrations do not establish a complete, reliable assistant working end-to-end.

### In development or awaiting end-to-end verification

- Reliable desktop application control and fully integrated conversational voice.
- Persistent memory with dependable retrieval and safeguards.
- Coordinated tool execution and autonomous workflows.

### Planned capabilities

- Adaptive three-monitor vision that prioritizes relevant windows and changed regions.
- Proactive but nonintrusive voice interaction.
- Distributed AI processing across two computers.
- Broader desktop integration and multimodal interaction.

## Other projects

### Heimoptes

**Status: Working prototype / Active development**

A Windows desktop entertainment hub combining music, internet radio, streaming, live feeds, and multi-monitor workflows.

Implemented features and automated tests exist. Some playback and integration acceptance checks remain unresolved; the application is not yet production-ready.

### Driftline

**Status: Working prototype / Active development**

A digital drawing application focused on flexible creative tools, streamlined workflows, and accessibility-oriented pen controls.

Several development milestones are implemented. Accessibility improvements, including stroke stabilization and editing assistance, remain in development or planned and should not be assumed fully functional.

### Aevora

**Status: Concept / Early development**

An experimental Linux-based operating-system project exploring Windows-style usability, application compatibility, modular architecture, and AI integration.

The initial architecture, vision, and roadmap are documented. No bootable operating system or functional runtime has been demonstrated.
